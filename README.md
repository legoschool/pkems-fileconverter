## 준비 조건

코랩판은 브라우저와 구글 계정만 있으면 됩니다. 코랩이 내 드라이브를 직접 연결하므로 PC에 따로 설치할 것이 없습니다.

Windows 앱과 파이썬판은 PC의 폴더를 읽습니다. 바꿀 폴더가 PC에 있으면 그대로 쓰고, 구글 드라이브에 있으면 PC에 구글 드라이브 데스크톱이 있어야 하며 그 폴더를 「오프라인으로 사용」으로 두어야 합니다. 「온라인에서만 사용 가능」으로 두면 변환기가 파일을 읽을 때마다 내려받아 느리고, 인터넷이 끊기면 읽지 못합니다.

1. [구글 드라이브 데스크톱](https://www.google.com/drive/download/)을 설치하고 자료가 있는 구글 계정으로 로그인합니다.
2. 파일 탐색기 왼쪽 「내 PC」 아래에 「Google Drive (G:)」가 생겼는지 봅니다.
3. 바꿀 폴더를 마우스 오른쪽 단추로 눌러 「오프라인 액세스 › 오프라인으로 사용」을 고릅니다.
4. 폴더 아이콘에 초록색 체크 표시가 붙을 때까지 기다립니다. 오프라인으로 둔 폴더 크기만큼 PC 저장 공간을 씁니다.

그다음 탐색기 주소 표시줄에서 폴더 경로(예: `G:\내 드라이브\수업자료`)를 복사해 원본 폴더 칸에 붙여 넣습니다. 구글 문서·시트·슬라이드는 PC에서 바로 읽히지 않으므로 DOCX·XLSX·PPTX로 내려받거나 코랩 3부로 바꿉니다.

변환한 마크다운은 [PKOS 기록장](https://legoschool.github.io/pkos-library/)의 「설정 · 백업 › Markdown · 텍스트 · 파일 가져오기」로 넣습니다. 블로그 글은 쓴 날짜·분류·원문 주소가 함께 들어가고, 원문 주소가 같은 글은 한 번만 들어갑니다.

## 왜 만들었나

우리는 지식과 경험이 가장 중요한 시대를 살지만, 정작 그것을 관리하는 체계는 없습니다.
내 기록은 외장하드·원드라이브·네이버 블로그·메모·유튜브·노션·구글드라이브에 흩어져 있고,
그렇게 조금씩 사라집니다.

AI 시대에는 **AI가 가장 잘 읽어낼 수 있는 형식**으로 바꾸어 두는 일이 필요합니다.
그리고 특정 도구에 얽매이지 않는, **내 것인 체계**여야 합니다.
사라지지 않는 기억, 되살아나는 기억으로 남도록.

이 도구는 그 첫 단계 — **흩어진 기록을 한 형식으로 모으는 일** — 을 맡습니다.

## 쓰는 법

1. 위 **[Open In Colab]** 배지 클릭
2. 맨 위 **준비하기** 두 칸 실행 → 구글 드라이브 연결 허용
3. 필요한 부(1·2·3)로 가서 **▶ 버튼**을 순서대로 클릭

- **1부**: 폴더 링크·ID 또는 경로 / **2부**: 폴더 경로 / **3부**: 폴더 링크·ID

- 새 PKOS 버전은 코랩에서 복사한 전체 경로와 Windows 내 드라이브 경로도 처리합니다.
- 중간에 끊겨도 다시 누르면 **이어서** 진행
- 한 파일이 실패해도 나머지는 계속 변환

> **드라이브 연결 승인 창은 반드시 직접 클릭**해야 합니다.

### 내 파일 없이 샘플로 먼저 테스트하기

4. 셀 아래에서 가사가 읽히는지 확인합니다. 원본은 왼쪽 📁의 `PKOS_샘플/원본`, 결과는 `PKOS_샘플/변환결과`에 있습니다. 파일 우클릭 → 다운로드로 저장할 수 있습니다.

## 🔒 개인정보 자동 가리기

업무 문서에는 이름·연락처·주소·계좌번호가 들어 있는 경우가 많습니다.
변환할 때 **자동으로 찾아 가립니다.** (기본값: 켜짐)

| 방식 | 예시 |
|------|------|
| **부분가림** | 홍길동 → `홍**` · 010-1234-5678 → `010-****-****` |
| **가림** | 900101-1234567 → `******-*******` |
| **삭제** | (빈칸으로) |
| **그대로** | 건드리지 않음 |

찾는 것: 주민등록번호 · 전화번호 · 이메일 · 계좌번호 · 카드번호 · 이름 · 주소 · 생년월일 · 차량번호

종류마다 방식을 따로 고를 수 있고, **이름 찾는 강도**도 3단계로 조절합니다.

### 변환 후 보고서

`_개인정보_보고서.md` 가 만들어집니다.
**어느 파일에서 무엇이 어떻게 바뀌었는지** 원본·변환값·확신도·주변 문맥까지 기록됩니다.

> ⚠️ **이 보고서에는 가리기 전 원본이 그대로 들어 있습니다.**

> (`보고서_원본표시`를 끄면 원본 없이 건수만 남깁니다)

### 정확도 — 솔직하게

실제 학교 업무 문서로 시험하며 다듬은 결과입니다.

| | 결과 |
|---|---|
| 초기 | 823건 탐지 — **대부분 오탐** (날짜를 계좌번호로, `학부모 안내`의 `안내`를 이름으로) |
| 개선 후 | **120건 · 이름 7명 전원 실제 인물, 오탐 0건** |

무엇을 고쳤나:

- 계좌번호는 **'계좌' 표시가 가까이 있을 때만** 인정 → 날짜 오탐 제거
- 이름 라벨을 **강·약으로 구분** — `학생`·`학부모` 같은 약한 표시는 3글자 이름만
- 조사로 끝나는 낱말 제외 (`성장을`, `지정및`)
- 띄어쓴 이름은 **모든 글자가 떨어진 형태만** 인정 → `이제 곧` 오탐 제거

**그래도 완벽하지 않습니다.** 특이한 형식은 놓칠 수 있고, 문장 속 이름은 잡기 어렵습니다.

## 기술 메모

**블로그 PDF 글 경계**
`YYYY/MM/DD HH:MM` + `blog.naver.com/<아이디>/<글번호>` 두 줄 연속 패턴.

**자동 감지** — 블로그마다 다른 값을 하드코딩하지 않습니다.
- 블로그 아이디 → 정규식 추출
- 페이지 푸터(`12 · 블로그이름`) → 표본 페이지에서 **반복 빈도**로 블로그명을 추론해 제거

**한글 `.hwp`** — 순수 파이썬 처리
- CFB(OLE) 컨테이너 → `BodyText/Section*` 스트림 → raw deflate 해제
- 레코드 순회 중 `HWPTAG_PARA_TEXT`(0x43)만 추출
- 문단 텍스트는 UTF-16 **코드 단위** 배열이라, 표·그림 제어문자는 8워드 블록째 건너뛰고
  이모지는 **서로게이트 쌍**을 합쳐야 함 (안 하면 저장 시 오류)

**한글 `.hwpx`** — ZIP + XML. 표준 라이브러리만으로 처리.

**표 복원** — 학교 문서는 절반 이상이 표 위주라, 표를 살리지 않으면 칸이 한 줄씩
세로로 늘어져 읽을 수 없게 된다. 그래서 표를 **마크다운 표로 되살린다.**

- `.hwp` : `CTRL_HEADER('tbl ')` → `TABLE`(행·열 수) → 셀마다 `LIST_HEADER`
  셀 좌표는 `LIST_HEADER` **8번째 바이트**부터 (열·행·열병합·행병합, 각 UINT16)
- `.hwpx` : `<hp:tbl rowCnt colCnt>` 안의 `<hp:tc>` + `<hp:cellAddr>`
- `LIST_HEADER` 는 **글상자에도 쓰이므로**, 표가 선언한 크기를 벗어난 좌표는 셀이 아닌 것으로 본다
  (이 검사를 빼면 빈 칸이 폭증해 한 문서가 300만 자까지 부풀었다)
- 칸이 20,000개를 넘으면 표 대신 내용만 풀어쓴다

**구글 문서** — 로컬에 실체가 없는 온라인 문서라 Drive API 로 내보내기 필요.
- 문서 → 마크다운으로 바로 내보냄
- 시트 → CSV 로 받으면 **첫 장만** 오므로 `.xlsx` 로 받아 **모든 시트**를 표로 옮김
- 슬라이드 → 텍스트로 받으면 **발표자 노트가 빠지므로** `.pptx` 로 받아 노트까지 옮김
- 세 가지 모두 최종 결과는 `.md` 하나로 통일

## 알려진 한계

| 한계 | 내용 |
|------|------|
| 서식 손실 | 표는 마크다운 표로 살리지만, 병합된 칸은 첫 칸에만 값이 들어감. 굵게·색·그림 위치는 단순화됨 |
| **스캔한 문서** | **변환할 수 없습니다** (아래 참고) |
| **옛 오피스 형식** | `.xls` `.ppt` `.doc` **미지원** (아래 참고) |
| 구형 `.hwp` 예외 | 암호 걸린 문서, 배포용 문서는 실패할 수 있음 |
| 처리 시간 | 100MB당 대략 1~3분 |
| 이미지 용량 | 사진이 많으면 결과가 원본보다 커질 수 있음 |

변환 전 **미리 확인(scan / inspect)** 으로 규모를 먼저 파악하는 것을 권합니다.

### 스캔한 문서는 변환되지 않습니다

종이를 스캔하거나 사진으로 찍어 만든 PDF·이미지는 **글자가 아니라 그림**입니다.
읽어내려면 글자 인식(OCR)이 필요한데, 이 도구는 **OCR을 하지 않습니다.**

- 이런 파일은 변환하지 않고 `_오류.md` 에 이유가 남습니다
- **원본 문서 파일(한글·워드 등)이 있으면 그것을 변환하세요** — 결과가 훨씬 좋습니다

### 옛 오피스 형식은 새 형식으로 저장한 뒤 쓰세요

`.xls` `.ppt` `.doc` 는 지금 형식과 구조가 완전히 달라 다루지 않습니다.
바꾸는 건 간단합니다.

| 옛 형식 | 이렇게 |
|---------|--------|
| `.xls` | 엑셀에서 열기 → **다른 이름으로 저장** → `.xlsx` |
| `.ppt` | 파워포인트에서 열기 → **다른 이름으로 저장** → `.pptx` |
| `.doc` | 워드에서 열기 → **다른 이름으로 저장** → `.docx` |

> **확장자만 바꾸는 것으로는 안 됩니다.** 파일 이름을 `.xls` → `.xlsx` 로 고쳐도
> 속은 그대로라 변환되지 않습니다. 반드시 프로그램에서 **다시 저장**하세요.
> (이 경우도 알아채서 `_오류.md` 에 안내가 남습니다)
